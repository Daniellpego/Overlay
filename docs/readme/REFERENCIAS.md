## Direção visual

- Conceito: **O jogo em primeiro plano.**
- Grafite, branco e verde-lima na apresentação editorial; os indicadores reais continuam configuráveis.
- Capa cinematográfica original com cenário fictício e faixa de métricas discreta.
- Mockup vetorial separado para explicar a leitura.
- Valores exemplificativos identificados como fictícios. Sem capturas do computador do autor, logos de jogos ou endossos inventados.
- Sem promessas de ganho de FPS, consumo garantido ou compatibilidade universal.
